# 🛸 Intellibiz
**The Operating System for Business Logic.**

Intellibiz is a unified, event-driven application engine designed to eliminate the "Anxiety of Correctness" in modern backend development.

### Why Intellibiz?
- **Fiscally Aware:** Built-in high-precision decimal math and tax engines.
- **Audit-First:** Every transaction is backed by a high-speed, immutable Rust ledger.
- **Secure by Default:** Automatic multi-tenancy injection and PII protection.
- **Developer First:** Zero boilerplate. Focus on your business rules, not the plumbing.

### Features
- 🚀 **Performance:** Rust-powered core with a TypeScript SDK.
- 🏗️ **Context-Aware:** Specialized contexts for HTTP, Jobs, and Events.
- 🛠️ **50+ Business Flags:** Configure complex logic via a single `intellibiz.config.ts`.
- 📊 **Admin Dashboard:** Real-time visibility into your ledger and business health.
