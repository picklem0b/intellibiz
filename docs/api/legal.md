# `@intellibiz/legal` API Reference

EULA signature tracking, software license key generation and verification, and GDPR compliance workflows.

---

## `legal.hasSignedLatest(user)`

Checks whether the given user has signed the latest version of the terms of service. Always call this before processing a purchase or granting access.

```typescript
import { legal, identity } from 'intellibiz'

const user = identity.getActiveUser()

if (!await legal.hasSignedLatest(user)) {
  throw legal.SignatureRequiredError()
}
```

Internally queries the signatures ledger scoped to the current tenant. The "latest" version is determined by the most recent terms version record in the governance store.

---

## `legal.recordSignature(userId, termsVersion)`

Records that a user has signed a specific version of the terms. Called when the user accepts the EULA on the frontend.

```typescript
await legal.recordSignature(user.id, 'terms-v2.1')
```

Writes an immutable `SignatureRecorded` entry to the Rust ledger with `userId`, `tenantId`, `termsVersion`, `timestamp`, and `traceId`.

---

## `legal.licenses.issue(options)`

Issues a new software license key. The key is generated by the Rust crypto suite using Ed25519 signing — cryptographically verifiable offline.

```typescript
const license = await legal.licenses.issue({
  plan: 'pro',
  userId: user.id,
  duration: '1y',  // ISO duration — '30d', '1y', '3m'
})

license.key        // 'A1B2-C3D4-E5F6-G7H8' — signed license key
license.plan       // 'pro'
license.expiresAt  // Date
license.tenantId   // Current tenant
```

Behavior is governed by `license` flags in `intellibiz.config.ts`:
- `license.autoRenew: true` — engine schedules renewal job before expiry
- `license.gracePeriod: '3d'` — access continues for 3 days after expiry during renewal

---

## `legal.licenses.verify(key)`

Verifies a license key against the Rust crypto engine. Returns the decoded license payload if valid.

```typescript
const result = await legal.licenses.verify('A1B2-C3D4-E5F6-G7H8')

result.valid      // true
result.plan       // 'pro'
result.expiresAt  // Date
result.expired    // false
```

---

## `legal.licenses.revoke(licenseId)`

Revokes a license immediately. The compensating action registered when `tx.licenses.issue()` is called inside a `commerce.transaction`.

```typescript
await legal.licenses.revoke('lic_abc123')
```

Writes a `LicenseRevoked` entry to the Rust ledger.

---

## `legal.licenses.check(licenseId)`

Returns the current status of a license.

```typescript
const status = await legal.licenses.check('lic_abc123')
// 'active' | 'expired' | 'revoked' | 'grace_period'
```

## GDPR — Cascading Purge

Triggered by `identity.deleteUser()` when `privacy.gdpr: true`. Automatically cascades across all linked packages:

| Package | Action |
|---------|--------|
| `@intellibiz/legal` | Anonymize signature records, mark licenses revoked |
| `@intellibiz/commerce` | Anonymize payment method references, retain transaction amounts |
| `@intellibiz/finance` | Retain ledger entries (tax compliance), anonymize user attribution |
| `@intellibiz/governance` | Record `UserDeleted` entry with reason |

When `anonymize: true` is passed to `identity.deleteUser()`, PII fields are replaced with `[ANONYMIZED]` rather than deleted — preserving financial records required by tax law.

## Domain Error Factories

```typescript
import { legal } from 'intellibiz'

throw legal.SignatureRequiredError()
// → HTTP 403 { error: 'SIGNATURE_REQUIRED', message: 'User must sign the latest terms before proceeding.' }

throw legal.LicenseExpiredError({ licenseId: 'lic_abc123', plan: 'pro' })
// → HTTP 402 { error: 'LICENSE_EXPIRED', licenseId: '...', plan: 'pro' }

throw legal.LicenseNotFoundError('lic_abc123')
// → HTTP 404 { error: 'LICENSE_NOT_FOUND' }
```
